== Descripción general

Ambiente de verificación funcional implementado con la metodología *UVM 1.2* para el DUT `fp_alu`, una unidad aritmética de punto flotante de precisión simple diseñada bajo el estándar *IEEE 754-2008* y compatible con la extensión *RV32F* de la arquitectura RISC-V.

[quote]
____
*Diseño e implementación de un ambiente de verificación funcional usando UVM para el DUT: FPU RISCV 32F bajo el estándar IEEE 754 para el procesador SIWA.*
____

El DUT (`fp_alu`) a verificar es completamente combinacional: no posee reloj ni reset. El ambiente UVM introduce un reloj a nivel de testbench para compatibilidad con el framework.


El código fuente del DUT está disponible en:
link:https://github.com/samuelca12/TFG-ALU-FP[enlace, window="_blank"]
 
Dentro de este proyecto, los archivos RTL se ubican en `dut/`.

== Arquitectura del DUT

[cols="1,3", options="header"]
|===
| Señal | Descripción

| `op_code_i [2:0]`
| Selección de operación (ver tabla de opcodes)

| `fp_a_i [31:0]`
| Operando A en formato IEEE 754 single-precision

| `fp_b_i [31:0]`
| Operando B en formato IEEE 754 single-precision

| `fp_c_i [31:0]`
| Operando C (usado en FMADD / FMSUB)

| `r_mode_i [2:0]`
| Modo de redondeo IEEE 754

| `fp_result_o [31:0]`
| Resultado de la operación aritmética

| `overflow_o`
| Bandera de overflow

| `underflow_o`
| Bandera de underflow

| `cmp_result_o`
| Resultado de operación de comparación (1 bit)

| `invalid_o`
| Bandera de resultado inválido (NaN / overflow / underflow)
|===

=== Mapa de opcodes

[cols="1,1,3", options="header"]
|===
| `op_code_i` | Mnemónico | Operación

| `3'd0` | `FADD`  | A + B
| `3'd1` | `FSUB`  | A − B
| `3'd2` | `FMUL`  | A × B
| `3'd3` | `FMADD` | (A × B) + C
| `3'd4` | `FMSUB` | (A × B) − C
| `3'd5` | `FEQ`   | A == B → `cmp_result_o`
| `3'd6` | `FLT`   | A < B  → `cmp_result_o`
| `3'd7` | `FLE`   | A ≤ B  → `cmp_result_o`
|===

=== Modos de redondeo soportados

[cols="1,1,3", options="header"]
|===
| `r_mode_i` | Código IEEE 754 | Descripción

| `3'b000` | RNE | Round to Nearest, ties to Even
| `3'b001` | RTZ | Round Toward Zero
| `3'b010` | RDN | Round Down (toward −∞)
| `3'b011` | RUP | Round Up (toward +∞)
| `3'b100` | RMM | Round to Nearest, ties to Max Magnitude
|===

== Estructura del ambiente UVM

[source,text]
----
├── tb_components/                ← ambiente UVM completo
│   ├── interface/                ← fpu_if
│   ├── packages/                 ← tipos, constraints y declaraciones DPI-C
│   ├── seq_item/                 ← fpu_seq_item + constraints
│   ├── sequences/                ← secuencia base + hijas + sequencer
│   ├── tests/                    ← test base + tests hijos
│   └── uvm_components/           ← agent, driver, monitor, env, scoreboard
├── testbench.sv                  ← top del testbench
----

[cols="2,4", options="header"]
|===
| Componente | Responsabilidad

| `fpu_if`
| Interfaz SystemVerilog; contiene clocking blocks para driver y monitor. Reloj generado en el TB para compatibilidad UVM (DUT puramente combinacional).

| `fpu_seq_item_c`
| Transacción UVM con enums tipados para `op_code_e` y `rm_mode_e`, variables `_rand` con constraints.

| `fpu_sequencer_c`
| Árbitro estándar de secuencias UVM.

| `fpu_driver_c`
| Traduce `fpu_seq_item_c` a estímulos en la interfaz, respetando el modelo de gating del DUT.

| `fpu_monitor_c`
| Observa la interfaz y publica transacciones completas al scoreboard y al bloque de cobertura.

| `fpu_scoreboard_c`
| Modelo de referencia bit-exact via DPI-C (Berkeley SoftFloat). Verifica resultado e indicadores IEEE 754 de forma independiente. BUG-001 está anclado como regresión permanente.

| `fpu_coverage_c`
| Covergroups por operación, modo de redondeo, categoría de resultado y cruces de cobertura.

| `fpu_virtual_sequencer_c`
| Coordinación de secuencias complejas multi-operación.
|===

NOTE: Solo se muestran algunos componentes del test. Para mas información, observa el documento escrito del proyecto.

== Flujo de simulación (UVM)

Todos los comandos se ejecutan desde la raíz del repositorio. Los marcadores `<...>` se sustituyen por valores concretos. La misma referencia está disponible en consola con `make help`.
Para mas información consultar `docs/makefile_UVM_doc.md`.
=== Ejecución completa

Corre toda la simulación con las tres semillas por defecto (469078601 1238983584 4170956088) y genera los reportes HTML de cobertura (individuales y fusionado):

[source,bash]
----
make all
----

=== En dos partes

Recompila conservando el historial de corridas y luego ejecuta la regresión con reportes:

[source,bash]
----
make remake
make regresion_mas_reportes_html
----

Abrir la cobertura en Verdi:

[source,bash]
----
make verdi COV_DIR=./reportes/regresiones/<REG_ID>/<test_name>/s<SEED>/cov.vdb
make verdi COV_DIR=./reportes/regresiones/<REG_ID>/cobertura_fusionada.vdb
----

=== Paso a paso (control de semillas)

Recompilación (equivalente explícito de `make remake`):

[source,bash]
----
make clean_all
make build_reference_model_obj
make testbench
----

Regresión por test individual:

[source,bash]
----
make regresion TEST=<NAME_TEST> SEEDS= NUM_SEEDS=N       # N semillas aleatorias
make regresion TEST=<NAME_TEST> SEEDS="SEED1 SEED2 SEEDN"
make cobertura_urg_individual COV_DIR=./reportes/regresiones/<REG_ID>/<test_name>/s<SEED>/cov.vdb
----

Regresión completa (todos los tests):

[source,bash]
----
make regresion_all SEEDS="SEED1 SEED2"   # semillas específicas
make regresion_all SEEDS= NUM_SEEDS=5    # N semillas aleatorias
make cobertura_urg_individual_all
make cobertura_urg_fusionada
----

[cols="1,4", options="header"]
|===
| Knob | Uso

| `TEST`
| Test a ejecutar en `regresion`.

| `SEEDS`
| Lista de semillas fijas (`"s1 s2 ..."`). Por defecto, las tres semillas de análisis.

| `NUM_SEEDS`
| Cantidad de semillas aleatorias; solo aplica si `SEEDS` queda vacío (`SEEDS= NUM_SEEDS=N`).

| `REG_ID`
| Etiqueta de la regresión (por defecto, un identificador temporal).

| `COV_DIR`
| VDB de cobertura a procesar con `urg` / `verdi`.
|===

== Flujo del modelo de referencia

El modelo de referencia (Berkeley SoftFloat / TestFloat) tiene su propio `Makefile` en `reference_model/`. Los comandos se ejecutan desde ese directorio, o con `make -C reference_model <target>` desde la raíz. Referencia rápida en consola con `make help`.

Para mas información consultar `docs/makefile_REF_doc.md`.

=== Construcción

Librerías Berkeley (`softfloat.a` + TestFloat) y objeto del modelo enlazable por el ambiente UVM:

[source,bash]
----
make build_all                    # librerías + reference_model.o
make build_reference_model_obj    # solo el objeto del modelo
----

=== Vectores y verificación N1

[source,bash]
----
make test_build_berkeleys_libraries   # softfloat.a vs slowfloat (testsoftfloat)
make build_testfloat_vectors          # vectores .tf  (knobs: TF_LEVEL, TF_SEED)
----

=== Tests standalone

[cols="1,4", options="header"]
|===
| Módulo | Flujo

| Runner
| Validación cruzada `tf_gen \| runner`. `make all_runner` (compilación + matriz + valgrind + sanitizers) o `make runner_run_matrix`.

| Driver
| Casos dirigidos (autojuez). `make all_driver` o `make driver_run`.

| Replayer
| Auditoría `tf_gen \| replayer \| tf_ver`. `make all_replayer`, `make replayer_run_matrix` o `make replayer_testfloat_sweep` (salida CSV).
|===

Ejecución conjunta (construcción + los tres módulos):

[source,bash]
----
make all
----

Limpieza:

[source,bash]
----
make clean                  # bin + logs + vectors (locales al modelo)
make clean_berkeley         # objetos/.a de softfloat y testfloat
make clean_build_reference  # build/ (reference_model.o)
make clean_all              # todo lo anterior
----

== Referencia de código

El proyecto sigue la convención de código SystemVerilog documentada en `docs/codigo_convencion.md`. Resumen de sufijos y prefijos:

[cols="2,1,2,1", options="header"]
|===
| Elemento | Sufijo/Prefijo | Elemento | Sufijo/Prefijo

| Enum type       | `_e`      | Input port      | `_i`
| Struct type     | `_s`      | Output port     | `_o`
| Class           | `_c`      | Wire interno    | `_w`
| Interface       | `_if`     | Flip-flop       | `_r`
| Package         | `_pkg`    | rand variable   | `_rand`
| Constraint      | `cn_`     | randc variable  | `_randc`
| Parameter       | `P_`      | Instancia RTL   | `u_`
| Localparam      | `C_`      | Covergroup      | `cg_`
| DPI import      | `dpi_`    | Assertion       | `a_`
|===
